# Public web search

Use Agent Reach/available upstream search backends only for public or explicitly authorized read-only research. Run `agent-reach doctor --json` before relying on an optional backend.

Preserve query, source, result URL/id, date/freshness and evidence class. Cross-check consequential claims with primary/official sources. Do not infer permission, demand or commercial truth merely from a search hit.

No CAPTCHA/access bypass, stealth rotation around blocks, or private-contact inference.
