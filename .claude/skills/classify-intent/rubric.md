# Rubric: classify-intent

A run passes only when:

- every declared input was inspected or explicitly marked missing;
- every required output exists and is structurally valid;
- material claims have evidence;
- no prohibited action occurred;
- the result stays within the mission contract;
- limitations and uncertainty are explicit;
- the skill stops after completion.

## Quality floor

This skill is evaluated at Sonnet 5 `xhigh` effort. A lower effort or non-Sonnet substitution is a failed run unless the user explicitly changes the contract.
