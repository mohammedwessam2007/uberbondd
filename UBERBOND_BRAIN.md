# UberBond Brain — durable cross-chat canon

This file exists so a new ChatGPT/Claude/Codex session does **not** restart UberBond from memory. It is a compact human-readable companion to `artifacts/uberbond-project-brain.json`.

## Startup law

Every new engineering session must:

1. fetch live `main` and record its SHA;
2. inspect open PRs and recent commits/CI evidence;
3. read `artifacts/uberbond-project-brain.json` and validate it with `src/project-continuity-contract.mjs`;
4. if the artifact baseline differs from live `main`, **refresh from the live repo instead of reverting to the artifact**;
5. never redo work already merged into `main`;
6. select the highest-value unfinished dependency-satisfied mission;
7. preserve external-proof boundaries instead of inventing customers, revenue, provider success or elapsed reliability.

Chat summaries are historical evidence. They are not allowed to override current code.

## One machine, one objective

UberBond is not merely a lead generator, Apollo clone, outreach tool, agency dashboard, SaaS bundle or collection of agents. Those are capability surfaces inside one private evidence-first economic operating system.

Its constitutional lineage is:

`identity → rights → jurisdiction → consent → delegation → coordination/control → mission matching → execution → evidence → proof/payment/credit → reputation/economic learning → immutable audit`

Its commercial loop is:

`signal → evidence → opportunity → offer → governed distribution → response → conversion/booking → delivery → cleared payment → accepted delivery → renewal/expansion → economic learning → autonomous reallocation`

The optimization target is **risk-adjusted cleared contribution profit per founder minute**.

Reach, impressions, followers, messages, leads, code volume, agent count and architecture complexity are not terminal objectives.

## Distribution doctrine

Distribution is treated as a portfolio, not a single channel. UberBond should be able to reason across cold outbound, partners/referrals, affiliates, lifecycle messaging, SMS/WhatsApp, voice, organic social, content/SEO, communities, marketplaces, creator partnerships, earned media, paid-media plans and product-led loops.

The allocator must prefer **trusted cleared contribution per founder minute**, adjusted for confidence, saturation, policy, reputation and consequence risk. A million clicks with no trusted economic receipt cannot outrank a smaller channel with verified cleared contribution merely because the vanity number is larger.

Cold outreach remains under the canonical outreach engine. Person-targeted communication remains under authority/consent/suppression policy. Social/public publication remains under the canonical communication consequence boundary. Partner/affiliate economics remain bound to the existing referral ledger and causal attribution spine. Paid-media planning never grants spend authority.

## Authority charter

Customer messages, provider calls, spend, deployments, DNS changes, credential changes, KYC/payment-account changes, production/customer mutations and money movement require explicit owner authorization. Internal planning, research, tests and reference-only contracts do not silently acquire those permissions.

## External truth that code cannot manufacture

The following remain external until real receipts exist: provider activation, sender/domain reputation, real distribution results, buyer responses, cleared payment, accepted delivery, refunds/disputes, renewal/expansion and sustained unattended operation over elapsed time.

A model/worker may report what it did, but worker prose is not economic truth.

## Historical-source limitation

The four uploaded conversation files used for this reconciliation are checkpoint-style exports/summaries, not proof that every raw message from every project chat was captured. The retained project context also cannot guarantee a byte-for-byte export of all chats. This canon therefore preserves the durable objectives and features supported by the available history, while the live repository remains the highest operational truth.
