# APEX FQC External Evidence Handoff — 2026-09-29

Status: **SECRET-FREE HANDOFF READY / EXTERNAL EVIDENCE NOT YET OBSERVED**

This is the handoff boundary for the fresh Frontier Quality Compression Wave 1 campaign.

It exists so UberBond can reach genuine external evidence without giving an independent custodian the optimizer, raw repository history, provider credentials, or authority over execution.

## Custodian job

The custodian receives only the request generated by:

```bash
node scripts/apex-fqc-external-evidence-doctor.mjs --custodian-request-only
```

The request contains:

- campaign ID and cryptographic campaign digest;
- architecture-roster digest, not a license to modify the architectures;
- suite version and task class;
- minimum fresh task count;
- latest architecture freeze timestamp;
- exact receipt-field contract;
- safe sealed-manifest field list;
- explicit prohibitions on evaluated-task reuse, raw-repository storage and optimizer/candidate pre-evaluation access.

The custodian keeps raw prompts and plaintext answers **outside Git and outside optimizer-visible state**.

The custodian returns only two secret-free JSON objects:

### Sealed manifest

One row per fresh task:

```json
{
  "taskId": "opaque-stable-id",
  "family": "task-family",
  "tier": "SEALED_HOLDOUT",
  "difficulty": 0.8,
  "answerDigest": "<sha256 digest>"
}
```

No prompt. No plaintext answer. No hidden rationale.

### Custodian receipt

The receipt binds:

- campaign and suite;
- manifest/corpus digests;
- task count;
- commitment time after architecture freeze;
- custodian/evaluator evidence pointers;
- fresh-generation claims;
- non-reuse claims;
- no repository/raw-answer leakage;
- secret-free status.

The local admission layer still treats these as claims backed by external provenance. It does not magically prove a dishonest custodian honest.

## Runtime evidence job

Provider identity and pricing remain separate from custody.

For every model slot, Wave 1 requires:

- observed `CALLABLE_NOW`;
- exact cognitive model identity and revision;
- exact reasoning setting;
- verified direct/Gateway transport;
- provider request evidence;
- exact frozen pricing mode.

A price from another mode does not count. For example:

`Opus Interactive != Opus Anthropic Batch`

The fresh campaign already refuses that substitution.

Where possible, runtime evidence should be produced through UberBond's existing Frontier Cognitive Fabric / canonical callability probe rather than a parallel proof system.

Discovery-only registry entries remain ineligible until their transport and runtime identity are actually admitted.

## Local intake

With evidence files present:

```bash
node scripts/apex-fqc-external-evidence-doctor.mjs \
  --manifest /safe/path/sealed-manifest.json \
  --custodian /safe/path/custodian-receipt.json \
  --runtime /safe/path/runtime-receipts.json \
  --pricing /safe/path/pricing-receipts.json
```

The intake:

- reuses the campaign's existing custodian and runtime-readiness gates;
- rejects secret-bearing or raw-holdout-bearing packet metadata;
- emits only digests, safe evidence pointers and unresolved gates;
- performs **zero provider calls**;
- spends **$0**;
- grants **no execution authority**.

## Why this is not bureaucracy

This boundary prevents the exact failure Frontier Quality Compression is trying to avoid:

a cheap architecture appearing to beat the frontier because it used old tasks, leaked answers, stale model identities, a different billing tier, or provider claims instead of measured execution.

The experiment is only interesting if the price advantage survives the same reality discipline as the quality claim.
