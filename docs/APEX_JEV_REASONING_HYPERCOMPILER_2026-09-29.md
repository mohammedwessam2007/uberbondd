## Public donor mechanisms reviewed

### Pareto-efficient multi-agent test-time scaling

ACL 2026 reports that mixture-of-agents and debate can outperform self-consistency under matched compute on harder tasks, and finds mixture-of-agents most efficient when parallel generations exceed sequential aggregation steps.

- https://aclanthology.org/2026.acl-srw.1/

Donation:
- parallel-first reasoning search;
- bounded sequential aggregation;
- adaptive rather than fixed test-time expansion.

### Debate diversity + calibrated confidence

ACL 2026 finds vanilla homogeneous debate can underperform simpler voting, while diverse initial viewpoints and confidence-aware updates improve results.

- https://aclanthology.org/2026.findings-acl.1694/

Donation:
- deliberately different reasoning perspectives;
- confidence as evidence about uncertainty, never proof;
- no homogeneous chatbot chorus.

### Identity-blind multi-agent reasoning

ACL 2026 documents self/peer identity bias and proposes response anonymization.

- https://aclanthology.org/2026.acl-long.650/

Donation:
- responders keep independent first passes;
- critique packets hide provider/model/profile identity;
- adjudication sees identity-blind answers and critiques;
- runtime retains provenance outside the model-facing packet.

### Adaptive test-time compute

Public 2026 work formalizes allocating more inference to difficult/unresolved problems rather than scaling all queries uniformly.

- https://arxiv.org/abs/2604.14853
- https://proceedings.iclr.cc/paper_files/paper/2026/hash/ae8d4084f418bb51575c2ca6c658a05b-Abstract-Conference.html

Donation:
- reasoning topology expands with uncertainty/novelty/stakes;
- easy tasks do not receive ceremonial swarms;
- APEX tasks do not silently downgrade semantic quality for cost.

### Context optimization

Microsoft's ACON work reports 26-54% peak-token memory reductions while largely preserving task performance on evaluated long-horizon tasks. 2026 work on interaction-aware forgetting further supports externalizing derived state before deleting reasoning history.

- https://www.microsoft.com/en-us/research/publication/acon-optimizing-context-compression-for-long-horizon-llm-agents/
- https://arxiv.org/abs/2609.29875

Donation:
- small resident kernel;
- stable cacheable prefix;
- minimum mission delta;
- immutable raw evidence remains retrievable;
- aggressive reasoning-history deletion is prohibited until task-relevant derived state is externally preserved;
- compression failure returns to higher-fidelity source.

### Speculative / programmatic tool execution

Microsoft's PASTE work reports lower agent latency from speculative tool execution on evaluated workloads. Anthropic documents programmatic tool calling, deferred tool loading, caching and context editing as composable mechanisms.

- https://www.microsoft.com/en-us/research/publication/act-while-thinking-accelerating-llm-agents-via-pattern-aware-speculative-tool-execution/
- https://platform.claude.com/docs/en/agents-and-tools/tool-use/manage-tool-context
- https://platform.claude.com/docs/en/agents-and-tools/tool-use/programmatic-tool-calling

Donation:
- speculate only read-only/reversible work;
- cancel dead speculative branches;
- use deterministic/programmatic batching for mechanical tool chains;
- defer large tool schemas;
- preserve cache-stable context.

### Provider harnesses

OpenAI's current Agents surface publicly documents automatic context compaction, multi-agent orchestration, programmatic tool calling and MCP support.

- https://developers.openai.com/api/docs/guides/agents

Donation:

DSPy optimizers such as MIPROv2 and GEPA similarly optimize prompts/program components from task traces and metrics.

- https://arxiv.org/abs/2408.08435
- https://arxiv.org/abs/2410.06153
- https://arxiv.org/abs/2502.04180
- https://arxiv.org/abs/2510.02669

Donation:

- mutation is anchored to observed failures rather than aesthetic rewrites;
- topology, perspectives, delegation, prompts, aggregation, verification, context, tools, reflex boundaries and stopping policy may all mutate in sandbox;
- training evidence and sealed holdouts remain separated;
- the architecture generator cannot see the sealed holdout or promote itself to production;
- successful mechanisms enter the reasoning Arena like any other challenger.

## Quality law

For APEX work, optimization is lexicographic:

1. verified reasoning quality;
2. reliability / false-positive control;
3. only then cost, founder minutes and latency.

No cheap model, router, Jev score, majority vote, vendor prestige, leaderboard position or cached historical preference may silently reduce the frontier semantic quality floor.

Cheap or specialized machinery may:

- retrieve;
- transform;
- batch;
- execute deterministic instructions;
- produce candidates;
- run read-only speculation;
- execute already-calibrated bounded semantic circuits.

It may not manufacture semantic authority.

## APEX reasoning topology

The new source compiler accepts normalized signals in [0,1]:

- uncertainty;
- novelty;
- stakes;
- irreversibility;
- ambiguity;
- verifiability;
- context pressure;
- tool latency.

It maps the mission into one of four execution families:

### DIRECT_FRONTIER

One frontier pass where the problem is bounded and verification is strong.

### PARALLEL_FRONTIER

Multiple independent frontier perspectives with minimal aggregation.

### BLIND_COUNCIL

Sealed independent passes -> identity-blind critique -> evidence-weighted adjudication.

### APEX_SEARCH

Parallel heterogeneous reasoning representations, frame breaking, falsification, unknown-unknown search, verifier design and selective sequential synthesis.

The topology is bounded by explicit frontier-call, parallelism, sequential-aggregation, cost and wall-clock budgets.

## Identity blindness

The runtime now builds content-addressed blind packets for review.

Model-facing objects contain:

- `candidate_01`, `candidate_02`, ...;
- result references;
- answer or critique content.

They do **not** expose profile ID, provider or model identity.

The runtime separately retains an identity-map digest and exact execution receipts for provenance. Anonymization never destroys auditability.

- APEX search with framebreaker;

Each task-class trial records:

- verified success rate;
- process score;
- false-positive rate;
- cost;
- latency;
- founder minutes;
- sample size;

Selection is quality-first. Only candidates inside a declared verified-quality delta may compete on cost/latency/founder minutes.

The Arena produces a **promotion candidate**, never production authority.

## Jev law

Jev is not the sovereign reasoner and is not a cheap replacement for frontier cognition.

Jev's role is to execute already-bounded semantic circuits at high frequency.

Correct sequence:

`frontier reasoning -> semantic circuit -> Jev shadow -> observed outcomes -> calibration -> reflex candidate -> deterministic candidate -> decompile on drift`

A circuit may answer questions such as:

- continue / stop;
- evidence sufficient / insufficient;
- retrieve / execute / escalate;
- contradiction severity;
- branch priority;
- context relevance.

It cannot create permission to message, spend, deploy, mutate credentials, move money or redefine Mohamed's goals.
