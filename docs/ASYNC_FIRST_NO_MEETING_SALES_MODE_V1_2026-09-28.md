# UberBond Async-First No-Meeting Sales Mode V1 — 2026-09-28

Status: extension of the Expected-Success Cold Email Compiler. Goal is to minimize founder synchronous meetings while preserving conversion and trust.

## Objective

Optimize:
expected cleared contribution profit / founder synchronous minute

subject to:
- no deception;
- buyer can request a call at any time;
- fixed-scope offers must be explainable and purchasable asynchronously;
- high-risk, bespoke, legally consequential, or ambiguous work can still trigger a human meeting gate.

## Funnel

1. Cold email: evidence + prework + micro-CTA.
2. Positive reply: send artifact immediately.
3. Async qualification: ask 1–3 compact questions by email/form.
4. Async scope: send exact deliverables, turnaround, assumptions, price, and acceptance criteria.
5. Async purchase: payment link/invoice.
6. Async onboarding: structured form / required access checklist.
7. Delivery: report/artifact + evidence.
8. Acceptance: simple approve/revise response.
9. Expansion: offer next fixed-scope module asynchronously.
10. Meeting only if buyer requests it or ambiguity/risk crosses threshold.

## Discreet language

Do not tell prospects "I hate meetings" or "I am lazy." Frame async as buyer convenience:

- "Happy to keep this async if that's easier."
- "I can send the scope and fixed price here so you can review it whenever."
- "No need to book time unless you'd prefer to."
- "If useful, reply 'scope' and I'll send deliverables, turnaround and price."
- "I can handle the next step over email."

## CTA progression

Touch 1:
"Want me to send it?"

After yes:
"Sent. If you'd like, I can also send the exact repair scope and fixed price here. No call needed unless you'd prefer one."

After scope interest:
"Reply with [1–3 qualification fields], and I'll send the fixed scope, turnaround and price."

After qualification:
"Here’s the scope: [deliverables]. Turnaround: [X]. Fixed price: [Y]. If that works, I’ll send the payment/onboarding link."

## Meeting gate

Default = NO MEETING.

Allow one meeting only when one or more are true:
- buyer explicitly requests it;
- scope is genuinely bespoke;
- multiple stakeholders must align;
- required access/security cannot be safely resolved asynchronously;
- contract/value exceeds a configurable threshold;
- ambiguity creates material delivery risk;
- regulated/legal/compliance issues require synchronous clarification.

## Founder-minute metric

For each opportunity track:
- synchronous meeting minutes;
- async founder minutes;
- AI/operator minutes;
- probability of close;
- expected contribution profit.

Prefer the path maximizing:
expected contribution profit / founder minute.

A higher close rate is not automatically better if it requires large amounts of founder time.
