# Avengers Execution Boundary

Current Avengers execution is an internal capability. It may call an explicitly activated, rights-cleared, inference-proven model profile for `NONE` / `LOCAL_PREPARATION` tasks and record the provider call. It may not convert that provider call into customer, payment, deployment, DNS, credential, publication, spend or other business-effect authority.

The execution boundary is intentionally narrower than UberBond's total future company authority. Later systems may delegate additional consequences only through existing UberBond authority/consent/effect controls. Avengers itself never grants them.
