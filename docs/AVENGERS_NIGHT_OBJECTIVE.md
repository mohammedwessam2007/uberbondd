# Avengers Night Objective

The overnight objective is not to maximize model count. It is to make the smallest high-leverage set of currently available models, skills, methods and agents operate as a measured team, then improve that team continuously.

Priority order:

1. prove callability and identity;
2. establish task-specific benchmark evidence;
3. assign planner/researcher/builder/critic/verifier/adjudicator roles;
4. run bounded internal DAGs with parallel-ready work;
5. preserve independent review and evidence;
6. fail over without widening authority;
7. feed observed outcomes back into routing;
8. discover and challenge the roster with new technology;
9. promote only measured improvements;
10. redirect the stronger runtime toward the current highest-value commercial/autonomy bottleneck.

A larger arsenal that cannot execute is worse than a smaller roster that produces verified progress.
