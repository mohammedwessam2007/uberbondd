# Avengers Role Map

This file defines functional roles, not superhero branding as evidence.

| UberBond role | Preferred supplier class | Examples | Required proof before runtime use |
| --- | --- | --- | --- |
| Planner | harness/model/method | ChatGPT company brain, Fable protocol, evidence-backed reasoning model | current canon + callable model/harness evidence where a model call occurs |
| Researcher | model/project skill/adapter | local/open model, Find Skills, Agent Reach on approved public surfaces | callability + source/rights/policy evidence |
| Builder | coding harness/model/method | Claude Code, Codex/OpenAI coding surface, local coding model, Superpowers method | repository scope + callable worker + tests |
| Critic | model/method | independent model, Task Observer method | independent task evidence; no authority widening |
| Verifier | model/deterministic/security method | separate model, deterministic tests, Mutation War, Superpowers, Strix only on owned/authorized targets | exact-head evidence; security scope where applicable |
| Adjudicator | harness/model/protocol | ChatGPT company brain, Fable protocol, independent strong model | prior-node evidence and explicit uncertainty |
| General fallback | model | any evidence-backed compatible profile | same activation/rights/callability/routing gates as primary |

A single supplier may fill multiple roles only when evidence supports those task classes. UberBond should prefer diversity for review/adjudication when it materially improves falsification, but agent count is not a goal.

The routing objective remains risk-adjusted contribution profit per founder minute, subject to authority, evidence, reliability, cost, latency and task fitness.
