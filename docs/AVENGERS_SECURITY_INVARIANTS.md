# Avengers Security and Truth Invariants

1. **No task-supplied endpoints or credentials.** Runtime identity comes only from the resolved roster produced by the doctor.
2. **No secret values in durable artifacts.** Profiles may name an environment variable through `apiKeyEnv`; they may not store the secret.
3. **Loopback discovery is observation-only.** Seeing a served model never activates it.
4. **Remote profiles require explicit approval evidence.** HTTPS alone is not sufficient.
5. **Exact model identity matters.** An inference response naming a different model fails callability proof.
6. **Revision, rights and pricing evidence are mandatory profile fields.** Weight visibility is not commercial clearance.
7. **Fresh routing evidence is required for exploitation.** Stale reputation cannot select a worker.
8. **Routing can only narrow an already-callable roster.** A benchmark cannot resurrect a disabled or unproven profile.
9. **Fallback cannot widen authority.** Every fallback is precompiled from the same approved roster.
10. **Required tools are executable dependencies, not prompt decoration.** A runtime-required tool blocks the node until runtime proof exists.
11. **Graph integrity is digest-bound.** Tampering with a compiled DAG is rejected before provider calls.
12. **Parallelism is bounded.** Dependency-ready work may run concurrently only within the configured cap.
13. **Provider calls are not business effects.** Current Avengers missions are limited to `NONE` / `LOCAL_PREPARATION` and cannot message customers, deploy, spend, move money or manufacture commercial truth.
14. **New technology enters through evaluation, not instant promotion.** Gamechanger/Open Model Universe/Capability Genome/N+1 discovery produces candidates first.
15. **No arbitrary downloaded model code execution.** Model/runtime installation and execution remain separate evidence-gated activities.
