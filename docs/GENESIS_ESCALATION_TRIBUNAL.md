# GENESIS Escalation Tribunal

The tribunal converts completed cognition receipts into an explicit next-layer decision.

Decisions:
- `IMPLEMENT_NOW`: bounded internal source prototype can be attempted now.
- `ESCALATE_LOCAL_SEMANTIC`: use a proven local semantic model before paying cloud/frontier cost.
- `ESCALATE_PAID_SEMANTIC`: allowed only when paid-provider authority is explicitly enabled.
- `WAIT_PAID_SEMANTIC_AUTHORITY`: semantic uncertainty exists but spend is not authorized.
- `WAIT_REALITY_EVIDENCE`: physical, energy, telemetry, or human evidence is missing.
- `HOLD`: below the current realization frontier.
- `ALREADY_IMPLEMENTED`: durable source realization exists.

The tribunal never grants spend or external-effect authority. It is a prioritizer and escalation compiler, not a feasibility oracle.
