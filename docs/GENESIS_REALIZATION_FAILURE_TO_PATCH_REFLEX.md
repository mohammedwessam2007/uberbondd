# GENESIS realization: Autonomous Failure-to-Patch Reflex

Candidate: `genesis-candidate-20260922-self-0007`

Status: **SOURCE IMPLEMENTED / REAL PATCH-QUALITY HYPOTHESIS UNVALIDATED**

This realization does not create another coding agent. UberBond already has the isolated self-maintainer, constraint-mutation engine, independent verification and review-only promotion path.

The new reflex sits in front of that machinery. It recognizes a deliberately small registry of known self-maintainer failure signatures and compiles bounded repair proposals with exact-base binding, source hints, required regression tests, a three-file / 250-line maximum, no patch-time network, no provider credentials, no auto-apply, no auto-merge and no business-effect authority.

Unknown or mixed failure signatures escalate instead of improvising.

The replay helper measures whether known signatures can avoid unnecessary stronger-cognition escalation without generating automatic proposals for unknown cases. It does not claim real regression-rate improvement until historical/held-out repository failures are replayed with accepted patch outcomes.
