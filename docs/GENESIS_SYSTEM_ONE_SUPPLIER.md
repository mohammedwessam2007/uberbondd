# GENESIS JEV / System-One supplier

This supplier is deliberately **not** a frontier model.

It is a deterministic, zero-cost first-pass critic for `CANDIDATE_CRITIQUE` jobs. It attacks each idea with baseline leakage, hidden assistance, coordination overhead, missing measurement, proxy mismatch, and authority/evidence gaps before more expensive cognition is allowed.

Its purpose is compression: obvious weaknesses should be discovered by the cheapest sufficient layer. Stronger models remain escalation suppliers for unresolved causal or semantic uncertainty.

The output is research evidence only. It cannot implement, promote, spend, contact anyone, or convert an internal hypothesis into external truth.
