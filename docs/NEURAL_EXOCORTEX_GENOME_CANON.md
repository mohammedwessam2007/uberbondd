# UberBond Neural Exocortex Genome Canon

## Mission

Build a private, evidence-grounded exocortex that continuously discovers the strongest publicly observable neural/cognitive software mechanisms, retains a final reference library of **1,000,000 deduplicated neural capability records**, and retrieves only the minimum sufficient verified capability bundle for each mission.

This is a capability architecture and search objective. It is not a claim that UberBond has achieved ASI, that one million records have already been harvested, or that repository popularity proves intelligence.

## Immutable scale law

- Final retained neural capability target: **1,000,000**.
- The one-million target is the final deduplicated reference exocortex corpus, not a temporary raw-repository count and not a 50K terminal shortlist.
- Completion may be asserted only from the external-corpus compaction manifest when `retainedCapabilityRecords >= 1_000_000` after canonical-identity dedupe.
- The active mission cortex remains small and bounded, currently at most 64 capabilities.
- A million retained references are not a million installed programs and do not create execution authority.

## Exhaustive-search truth boundary

GitHub repository search has observable-result limits. UberBond therefore partitions by neural family, seed, star band and creation window. Saturated partitions split by date, then repository-size bands. A still-saturated leaf remains explicitly unresolved rather than being silently counted as complete. The machine may continue adding lawful refinement dimensions, but it must never claim exhaustive GitHub coverage without evidence.

## Single security perimeter

The Neural Exocortex does not own a weaker parallel admission system. A discovery record may enter reference memory immediately, but an executable neural supplier must exist as a canonical Capability Genome object and satisfy the existing admission/security/permission/benchmark lifecycle.

Manual flags on a neural discovery record cannot create callability or consequence authority.

## Whole-brain binding

`neural-exocortex` is a cognitive organ bound into the existing UberBond cognitive graph. It receives world/capability/model/context evidence and supplies mission-relevant capability knowledge to the World Brain, Avengers and MAX Council while returning learning to Capability Genome and Economic Memory.

Graph edges are information relationships only. They never grant customer, deployment, messaging, payment, trading, credential, spend or production authority.

## Resident operation

The neural harvester is a separate read-only network service/timer. It is intentionally not placed inside the private-network sovereign revenue continuum, so a GitHub outage, rate limit or long neural harvest cannot pause the 24/7 money machine.

The resident cycle is:

`harvest -> persist batch -> compact deduped external corpus -> emit brain receipt -> repeat`

A dedicated installer provisions the external corpus directory, read-only GitHub network authorization and systemd timer. Physical-runtime activation still requires executing that installer on an owner-controlled UberBond host; source presence alone is not a runtime receipt.

## Permanent truth laws

- One million retained records do not prove ASI.
- Repository discovery does not prove capability behavior.
- Capability behavior does not prove safety.
- Safety does not prove task advantage.
- Benchmark advantage does not create external authority.
- Reference memory is not active execution.
- Active execution remains bounded by the exact mission and existing authority gates.
- Revoked or degraded capabilities must be removable from active selection without deleting provenance/history.
