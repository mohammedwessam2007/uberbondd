# UberBond 50K Neural Repository Atlas

## Mission
Index at least 50,000 distinct public repositories that may contribute useful capability atoms to UberBond. Do not vendor or activate 50,000 dependencies.

## Why
The highest-leverage path is broad external discovery plus ruthless selection: discover the world, canonicalize identity/provenance, reject unsafe or legally unusable candidates, extract capability atoms, benchmark substitutes, and activate only the minimum sufficient winners.

## Coverage
The atlas intentionally spans foundation models, inference/serving, training, agents/orchestration, memory/context, retrieval/search, evaluation/reasoning, multimodal systems, robotics/embodied AI, code intelligence, scientific AI, optimization/search, distributed compute, data/knowledge systems, reliability/observability, protocols/tooling, automation/browser systems, commercial autonomy, formal math/reasoning, and efficiency/compression.

## Pipeline
DISCOVER -> CANONICAL IDENTITY -> PROVENANCE -> LICENSE REVIEW -> DEPENDENCY REVIEW -> SEMANTIC DEDUPE -> CAPABILITY ATOM EXTRACTION -> BENCHMARK -> ECONOMIC TOURNAMENT -> SANDBOX -> APPROVE -> ACTIVE / REPLACED / REVOKED / ARCHIVED.

Repository popularity is a discovery prior only. Stars never grant trust, execution authority, network authority, customer authority, deployment authority, messaging authority or spending authority.

## 50K law
The atlas may say `NEURAL_ATLAS_TARGET_SATISFIED` only after observing at least 50,000 distinct eligible repository identities. Until then it must report `NEURAL_ATLAS_MORE_DISCOVERY_REQUIRED`.

## Integration with Revenue Decision Desk
External repositories are suppliers competing in UberBond's mechanism market. A candidate capability should ultimately be compared against NO-SKILL, CURRENT and alternative candidates on reliability, latency, cost, security evidence, founder minutes saved and observed economic effect. The Revenue Decision Desk can then choose whether a capability improves risk-adjusted cleared contribution profit per founder minute.

## Integration with agent-native commerce
Capabilities that improve machine-readable discovery, bounded delegation, structured actions, receipts, reconciliation or agent-to-agent interoperability get direct commercial relevance because they can make UberBond easier for authorized machine customers and operators to use.

## Current truth
This patch creates the 50K discovery/tournament architecture and query atlas. It does not claim 50,000 repositories have already been fetched, reviewed or activated. Network harvest must generate measured receipts before the count becomes evidence.
