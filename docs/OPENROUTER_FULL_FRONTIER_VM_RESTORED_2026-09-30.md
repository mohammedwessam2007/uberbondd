## Where TypingMind belongs

TypingMind is the human cockpit and a convenient native multi-agent fallback.

Its v3 role sequence:

```
MiMo -> Sol -> DeepSeek -> Opus
```

is **not** the primary architecture.

It is a processor plan used only after the Frontier VM decides that:
- the work is not already exact/reusable;
- Jev cannot settle it within certified bounds;
- the Cognitive Supercompiler cannot remove more work;
- a multi-model preparation path is cheaper than direct Crown;
- the final quality contract remains protected.

For short tasks the Compute Auction may choose direct Opus.

For repeated tasks it may choose exact replay, code or a certified Jev circuit and invoke no chat model at all.

For difficult open-ended work it may awaken adaptive cheap branches, Sol, task specialists, a second Crown or the full Pantheon.

## JEV

Jev is a first-class organ.

It is not a TypingMind persona.

It is the semantic interrupt / branch-control layer.

It evaluates bounded typed questions over shared state:

- relevance;
- novelty;
- uncertainty;
- evidence sufficiency;
- contradiction severity;
- materiality;
- stakes;
- reversibility;
- branch viability;
- value of more search;
- worker disagreement;
- model suitability;
- context loading;
- cache candidate equivalence;
- Crown necessity;
- drift;
- applicability-domain confidence.

Uncertified Jev can always request **more** review.

It may suppress required Crown review only inside an explicitly certified bounded domain carrying a valid Applicability Passport.

Promotion ladder:

```

```
