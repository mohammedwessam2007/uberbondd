## Exact next owner action

1. **Give the exact domain name(s)** you purchased on GoDaddy. No

3. Once both exist, activation re-runs automatically through the same

   blocker (`BLOCKED_PROVIDER_AUTH` if step 2 isn't done yet,
   `BLOCKED_DNS`/`BLOCKED_MAILBOX` if DNS/mailbox auth isn't clean,

## What this action does NOT do

- Does not spend money.
- Does not create any external effect by itself (registering a domain name
  in UberBond's own records is a local write, not a purchase or DNS
  change).
- Does not require choosing an architecture — just the domain name(s) and,
  separately, a provider decision.
