# Operator note

After this branch is verified and merged, the founder-facing activation surface is `/admin.html`.

Enter the existing `ADMIN_TOKEN` in the page-memory field and press **START UBERBOND OUTREACH**. The control will either:

- refuse and name the live blocker; or
- wake the worker, release the persisted outbound pause, and start the bounded processing pulse.

The button does not turn a dry-run runtime live by itself. That separation is intentional: deployment/environment authority remains outside the browser and cannot be silently widened by client code.
