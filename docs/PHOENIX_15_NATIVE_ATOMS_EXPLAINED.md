# The 15 native PHOENIX function handlers

These are code-backed, locally admitted **deterministic zero-external-effect** atoms. Each description explains the intended software responsibility based on its source-export name. Success/failure fixtures require current-runtime verification. These are not the 1,560 research proposals.

1. **`proof.compile`**. Compiles content-addressed proof/evidence dependency graph with explicit witness links.
2. **`proof.route-missing`**. Routes missing proofs into classified evidence-collection requirements without fabricating evidence.
3. **`founder.exception-prioritize`**. Prioritizes bounded human-only founder exceptions, with the maximum size 3.
4. **`institution.compile-cell`**. Compiles bounded institutional process/capability cells from typed evidence.
5. **`strategy.minimax-regret`**. Chooses defensible strategies across uncertain adversarial scenarios using minimax regret.
6. **`authority.revoke-subtree`**. Revokes an authorization and its dependent delegation subtree in a local signed graph representation.
7. **`world.simulate-counterfactual`**. Computes bounded counterfactual scenario comparisons for a modeled world state.
8. **`theory.form-evidence-bound`**. Forms testable theories tied to supplied evidence rather than claiming unsupported discoveries.
9. **`causal.assess-witness`**. Assesses whether a claimed causal relationship has adequate witness evidence.
10. **`evaluator.coevolve`**. Evaluates coevolution of candidate systems and test/evaluation ecologies in bounded simulation.
11. **`architecture.generate-rivals`**. Generates rival design candidates for comparative evaluation.
12. **`policy.evolve-generations`**. Tests bounded policy evolution over candidate generations.
13. **`ontology.invent-language`**. Constructs bounded new conceptual vocabulary/formal language proposals.
14. **`economy.compile-dsl`**. Compiles and checks a limited domain-specific language for economic operations.
15. **`company.compile-genome`**. Compiles a structured specification of company architecture/capabilities.

Exposed through the optional, newly built `phoenix_invoke_native` MCP tool. No automatic spending, messaging, remote supplier installation or production mutation.
