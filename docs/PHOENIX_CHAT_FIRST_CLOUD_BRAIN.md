`Founder <-> ChatGPT cloud reasoning -> PHOENIX direct MCP tools -> verified local atoms -> source/evidence receipts`

When repository modification is needed: `ChatGPT -> Chat On Steroids Core -> connected remote Codespace -> isolated current-main worktree -> test and preserve`.

The model reasons on OpenAI cloud, not the founder's iPad. The native PHOENIX executor runs remotely where its authenticated server/workspace is hosted, not inside the ChatGPT model. The Codespace/tunnel can sleep, disconnect or have provider limits; confirm reachability rather than claiming 24/7 readiness.

**Important:** regular ChatGPT chat is *not* a callable model API that PHOENIX can use independently after a conversation closes. Work/Codex and API-backed unattended operation are optional future routes, not prerequisites for founder-interactive missions. There is no unlimited ChatGPT or tool-use promise and no authorization for API fees.
