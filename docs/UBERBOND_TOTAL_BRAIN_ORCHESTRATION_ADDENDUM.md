## Permanent doctrine

UberBond must preserve and continuously improve a provider-neutral orchestration layer across ChatGPT/company-brain work, Claude Code/software-factory work, Codex/OpenAI coding work, and UberBond's own runtime.

The durable pattern is:

`objective + acceptance criteria + current evidence + authority ceiling -> compact orchestration packet -> planner/adjudicator -> bounded dependency DAG -> callable-worker validation -> ownership-aware parallel execution -> independent verification -> adjudication/integration -> final verification -> durable receipt -> learning -> search for a better orchestrator`

The planner is not sovereign. Orchestration never creates authority, commercial truth, payment truth, customer acceptance, credentials, or external-effect permission.

UberBond's job is not merely to remember Fable. UberBond must continuously search for orchestrators, skills, agent frameworks, model-routing patterns, verification systems, memory/task-state systems, and better mechanisms that can outperform the current orchestration baseline.

`Gamechanger / Find Skills / public OSS discovery -> provenance + exact revision -> license/security/data/effect review -> dedupe -> mechanism extraction -> Fable N+1 tournament -> held-out behavioral comparison -> founder-minute/economic comparison -> compose/promote/reject -> monitor -> replace/revoke -> continue searching`

- replaceability;
