# UberBond Ultimate Graph

## Purpose

The Ultimate Graph is UberBond's repository-complete self-map. It exists so the living brain does not reason from a hand-picked architecture diagram while thousands of real implementation details sit outside its awareness.

The graph is compiled from the exact checked-out repository state. It is not a chat summary and it is not maintained by manually enumerating favorite features.

## Layers

1. **Feature Genome**
   - walks the repository tree;
   - preserves every repository artifact as an addressable node;
   - classifies files into feature families and living cognitive organs;
   - records JavaScript module import edges, package operators, readiness capabilities, activation gates, Total Brain memory atoms, GENESIS canon and donor lineages.

2. **Feature Atom Atlas**
   - extracts exported functions, classes and values;
   - preserves package operators, readiness capabilities, gates, GENESIS ideas, Total Brain memory atoms and historical donor programs as addressable atoms.

3. **Synaptic Map**
   - connects artifacts, feature atoms and cognitive organs;
   - preserves import, implementation, test, runtime-receipt, gating, operator, memory, donor and organ-relation topology;
   - fails closed on orphan artifacts, feature atoms or organs.

4. **Repository Deep Atlas**
   - inspects every Feature Genome artifact;
   - keeps non-text and unsupported files represented at artifact level;
   - deeply indexes supported textual source, tests, workflows, config, canon, memory and UI surfaces;
   - extracts code symbols, test cases, HTTP routes, environment bindings, SQL objects, workflow steps/actions/triggers, document sections/checklist assertions, UI surfaces and JSON configuration keys;
   - records per-file coverage and refuses silent per-file truncation.

5. **Ultimate Graph**
   - preserves the complete Synaptic Map;
   - adds every Deep Atlas declaration as a connected graph node;
   - inherits artifact-to-organ bindings for deep declarations;
   - verifies that artifacts, feature atoms and deep features are all present and that no graph node is orphaned;
   - emits an exact digest for stale-map/amputation detection.

## Memory law

The full machine-readable graph is written to:

`artifacts/cognitive/uberbond-ultimate-graph-latest.json`

Every whole-brain cognitive cycle binds the graph digest and coverage summary into:

`artifacts/uberbond-cognitive-cycle-latest.json`

The cycle therefore remembers which exact repository self-map it used. A stale or disconnected graph is refused instead of entering cognitive memory.

The hourly Gamechanger/Whole-Brain workflow compiles, tests, stores and uploads the Deep Atlas and Ultimate Graph alongside the ordinary cognitive-cycle receipt.

## Truth boundary

The graph proves structural repository evidence only. Presence of a function, test, route, workflow, config key, memory statement or edge does not by itself prove runtime reachability, correctness, buyer demand, market value, production status or consequence authority.

No graph edge grants repository-write, merge, deploy, payment, customer, DNS, credential, spend or production authority.

## Anti-amputation invariant

The intended invariant is:

> If a file exists in the repository, the Feature Genome knows it. If a supported textual declaration exists inside that file, the Deep Atlas can address it. If it is addressable, the Ultimate Graph connects it into UberBond's self-model. If the map becomes stale, truncated or disconnected, cognitive memory must refuse it.

This is the difference between a diagram of UberBond and UberBond actually knowing its own body.
