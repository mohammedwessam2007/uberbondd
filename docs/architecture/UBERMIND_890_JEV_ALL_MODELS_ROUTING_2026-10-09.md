Expensive clean Crown baseline is preserved for novel, uncertified work where required.

**Economic selection:** expected all-in cost (input/output/cache/batch + tool/runtime/evaluator overhead + retransmissions + risk) is weighed only among quality-eligible, current, admitted alternatives. Distinct model lineages offer error diversity. Parallelism must be bounded by expected marginal quality gain; majority vote never automatically certifies a frontier answer.
