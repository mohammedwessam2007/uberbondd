### What Ω42 adds instead of duplicating those donors

`src/ubermind-omega42-agent-tree-console.mjs` turns a **W40 route** into a deterministic, digest-addressable, *truthfully labeled* stage model. It renders a static, accessible, offline HTML command center with director → Jev-style local router → lead → optional existing specialists → scoped explorer/researcher (unassigned) → worktree / peer receipt bus → native QA → independent review → PHOENIX. Model names describe proposed routing only. It shows `NOT_OBSERVED` and `NOT_ASSIGNED` for stages with no live receipts. Input screenshots cannot grant role callability or developer authority.

`scripts/ubermind-omega42-agent-tree-console.mjs` accepts one bounded W40 JSON contract and runs **only three fixed native W40/W41/Ω42 test files** using Node (no arbitrary shell from user input, no network, no model calls). It checks checkout cleanliness and exact HEAD before labelling a local test packet matched; externally supplied packets remain **REPORTED**, not independently authenticated. It can write a fully escaped offline HTML file (no network/CDN, no inline JavaScript, no hosted service). The CLI reports true local test command outcomes separately, and never promotes local source verification into live model/peer/API/runtime/customer quality claims.

*Important limitation:* Even a clean checkout and passing selected tests only prove those specific modules passed. They do **not** prove real task performance or actual agent-model usage. W40 routes remain proposals and W41 remains economic modeling, not provider execution. Artifacts/HTML cannot be publicly published or given credentials without explicit authority.

```bash
node scripts/ubermind-omega42-agent-tree-console.mjs docs/architecture/UBERMIND_OMEGA42_EXAMPLE_CONTRACT.json /tmp/uberbond-omega42-agent-tree.html
```

The example digest strings are test fixtures, **not actual hashes of tasks/source/rubrics**.
