## The actual new mechanism

Claude can call `node scripts/ubermind-w40-route-doctor.mjs <contract.json>` *in its own checkout* for bounded verified-intent decisions. This runs **without model or network calls** and returns the model, effort, conditional specialist roles, max turns, next live gates and warnings. Source SHA strings supplied by the caller are never accepted as cryptographic proof; exact work gets `NATIVE_REVERIFY` rather than an automatic pass. Reviewer calls are postponed until native checks fail or remain inconclusive. Critical tasks start directly with Opus instead of paying an unnecessary Sonnet planning tax. Peer teams require *actual matching evidence* of quality plus full-workflow economic benefit, disjoint worktrees and independent subtasks.
