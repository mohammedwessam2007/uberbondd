### Specific operative contracts

- **Director:** Sonnet 5.5 medium on scoped jobs, but **start Opus 5.5 HIGH directly** for intrinsically difficult/high-consequence reasoning. For new tasks, never pay two leads for the same planning answer. Full primary Opus rather than artificial downgrading when necessary.
- **Native gate:** exact source reverify, unit/acceptance SHA graph, JEV local NOUL/CHOICE/SCORE, original 890/GENESIS pointer retrieval, source dedupe and regression tests. Model effort NONE. JEV's separately paid provider is not authorized under strict existing $20 Claude Pro spend.
- **Haiku scouts:** LOW; read/Grep/Glob only, <=6 turns each, no credentials/writes. One initially; additional scouts only for actual independently useful source slices. Every subagent prefix/input/output counted separately. 5.5 short-tier rate applies only if **each prompt** is no more than 100K input.
- **Sonnet implementation:** MEDIUM for well-scoped work, HIGH if complex. Worktree isolation with typed inputs/outputs and unit tests.
- **Opus Crown:** HIGH for frontier reasoning; optional XHIGH/MAX only where supported and genuinely required; don't spend on ceremonial final passes where native evidence already satisfies acceptance.
- **Falsifier:** Sonnet HIGH, max 6 read-only turns, **only** on native-test failure or inconclusive material-risk test (W40).
- **Micro-auction:** `src/ubermind-w41-proof-constrained-route-auction.mjs` computes the least expensive *caller-attested* task-part path including every declared call; fallback is Opus on absent/mismatched quality proof or expensive peers. Frontier model units may not downgrade from Opus. **It does not authenticate evidence, run tasks, change models or claim quality parity.** The real execution system must authenticate matching acceptance before any real promotion.
- **Owner/legal/security gate:** no spend, side effects, customer outreach, credential reads, deploy, publication or extra paid API authorized by the router. Existing UberBond owner authority remains mandatory.
