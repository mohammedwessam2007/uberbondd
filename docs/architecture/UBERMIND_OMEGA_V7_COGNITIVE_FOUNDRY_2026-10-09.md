## What makes this materially better than a fixed 3-model tree?

**1. Founder prompt is the API.** The user opens normal Claude and simply enters their task. No requirement to send commands or select teammates first. The Claude app cannot silently switch the model selected for that conversation or invoke a separate Jev/OpenRouter account; in Claude Code, the /model and opusplan facilities can route between eligible models only when actually available.

**2. Intelligence Escrow** means UberMind passes compact source/policy/acceptance receipts to a worker, not raw conversation histories or entire canons. It records the minimum context needed to reproduce decisions, expected file SHA, relevant founder idea ID, permissions, and current failure states. No loss of unique source data: originals stay in source, indexed and retrievable.

**3. Cognitive Pressure Valve** classifies each new prompt by novelty, consequence, reversibility, uncertainty, missing evidence, and actual private subscription usage (if available to the product). The output is one of four *strategies*, not a fake API dispatch: 
- EXACT: verify existing applicable procedure, then run ordinary code without a fresh model request.
- SONNET SOLO: answer or implement one normal task without a team.
- OPUS CALL: a full high-effort architecture/invention/critical-decision pass on a truly hard problem, then compress the **proved specification** for routine execution.
- BOUNDED TEAM: only for truly independent modules with clear contracts. Dedicated Sonnet implementation and adversarial tester; short Haiku source scout only if available and worth included usage. An agent count is **not** a performance metric.

**4. Jev Hyperreflex, with its real boundaries.** TypeSafe Jev 1.13 specializes in NOUL, CHOICE and SCORE. Existing W11–W22 source mechanisms include decision tensors, exact scoped reuse, durable cross-worker single-flight, pending claim and page-fault inspection, fixed-price/budget admission, public-source checks, unknown provider-charge quarantine and runtime verification. This is an optional **separately authorized and billed** provider route, never a free invisible feature of normal Claude Pro. When no route is authorized, use ordinary rules and Claude's existing reasoning. Never assign independent Crown authority to Jev confidence or screenshot probabilities.

**5. Contracts live in executable workflows.** Task DAG, file owners, interface contracts, scriptable deterministic steps, test command, expected source hash, allowed external effects, stop/rollback conditions, and verified evidence receipts. Claude Code worktrees and teammate communication, if configured, remain distinct from merely stating "zero lock conflicts". Scripts execute boring steps; humans/models tackle unresolved meaning.

**6. Frontier Council, not an Opus monarchy or token swarm.** Sonnet 5.5 is the default engineer. Opus 5.5 is summoned for novel deep architecture, difficult science/strategy, critical ambiguities, or a final residual semantic gap. Actual qualified Sol/Astra/specialist market challengers require separate entitlement and task-class evidence. Haiku is narrow, bounded, source-grounded and conditional. Fable 5.1 / Advisor remains locked behind paid/additional integration and is not included in a strict $20 Pro setting. A model-role recommendation is not an observed runnable team.

**7. Proof-carrying learning.** Every accepted result becomes a PHOENIX pointer and, where actually validated, a candidate reusable deterministic method. Self-improvement happens through observation → candidate → adversarial check → permission gate → reversible promotion, not by declaring recursive competence. Distinguish source code, CI pass, exact deployment, accepted delivery, provider charge, and cleared revenue.
