## Date and evidence boundaries

- All calendar dates and commit counts are GitHub **UTC**, not Cairo civil days. Timezone conversion can move evening UTC commits to the following local day.
- The main-history 6,243 are all commits **reachable in the frozen main history**, not every commit ever created on private branches, deleted refs, chats or uploads. Branch and PR indexes expand the audit surface but **do not** close this completeness gap.
- For each commit, the exact GitHub object is the letter-for-letter original; index subjects normalize whitespace, truncate long first lines and redact token-looking strings. The 6,243 commit patches have **not** all been fetched or semantically reviewed line by line in this pass. - Zero in the date calendar means zero events *in that particular source stream*, not no work. PR creation dates, commit author dates, merge dates and source-file creation dates are not synonymous.
- A PR labeled closed is not synonymous with merged. Code existence ≠ deployment; deployment ≠ observed use; tests ≠ customer outcomes; idea text ≠ proof.
- No new customer outreach, purchase, infrastructure deployment, DNS, payments, or bulk source mutation occurred here. This audit writes only additive forensic documentation to an isolated review branch.
