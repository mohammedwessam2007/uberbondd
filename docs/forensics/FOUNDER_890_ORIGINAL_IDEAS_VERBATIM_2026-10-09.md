## 0001. THE CAUSAL COMPILER

**Original hypothetical IQ:** 10³⁴

Instead of programming machines, program **cause-and-effect chains**. Give it an end state and it discovers the minimum chain of interventions that would make that state emerge across physical, biological, economic, and computational systems.
