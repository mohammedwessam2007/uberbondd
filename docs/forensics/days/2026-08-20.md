DEFECT 1 - Node's fetch silently ignores HTTPS_PROXY.

not unless NODE_USE_ENV_PROXY=1. In a proxied environment the proxy is what
carries the usable credential, so every GitHub API call from the worker
returned 401 while an identical curl returned 201. Measured side by side:

  curl via proxy                   -> 201
  curl --noproxy '*'               -> 401
  node fetch (default)             -> 401
  node fetch NODE_USE_ENV_PROXY=1  -> 200

untouched on an ordinary host where none exists.

DEFECT 2 - that failure would have stranded a real task.

held by an already-dead worker until it expires. Added a GET /user credential
preflight that refuses to claim anything if it fails. One request removes the
whole class of outage.
