## W12 code: useful output throughput

`src/decision-franchise.mjs` adds `executeCertifiedFranchiseWorkBatch`:
- Accepts only **already-ACTIVE, trust-pinned, unexpired, side-effect-free** finite-domain franchises plus current context; the caller cannot promote a model or invent authority through an output.
- Compiles exact finite-domain executor **once** per bounded batch (1–4096), executes all requested tasks, and returns **materialized decisions**, exact per-task/full-context semantic hashes, a batch content hash, and distinct-state counts.
- Differentially cross-checks each unique projected semantic state against the existing interpreted `executeDecisionFranchise`, refusing compiler/interpreter divergence and nondeterministic canonicalizers.
- Atomic output semantics: any task missing a relevant field, out of scope, duplicated, ambiguous, affected by source/Crown drift, or violating effects causes the **entire output batch to be withheld**. There is never a partial user-visible assertion of success.
- Reports separately **distinct full task hash count** and **distinct certified semantic state count**. Distinct request IDs or irrelevant text do not become newly independent reasoning operations. Returns zero model calls and zero external side-effect authority.
- Returns `independentlyVerifiedRealDemandCount=0`, `independentPairedQualitySamplesAdded=0`, `economicMultiplier=null`, `global33333xConfirmed=false` because executing code does not establish independently verified real demand, Opus/Sol-equivalent novel reasoning, a provider bill or the cheapest valid reference.

`tests/ubermind-certified-work-batch.test.mjs` checks materialized 1024-output behavior, unique states=2, atomic no-leak refusal, duplicate IDs, context drift, unsafe effects, nondeterministic canonicalization, and capacity bounds. Wired into actual `scripts/jev-native-runtime-tests.mjs` Node startup regression suite.
