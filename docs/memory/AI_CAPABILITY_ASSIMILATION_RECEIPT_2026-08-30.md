## Key architectural decisions

### Find Skills
Approved as a candidate-discovery skill feeding UberBond's existing Automation Capability Acquisition Loop.

### Claude Code Setup
Approved as a read-only automation auditor. Recommendations never auto-install or supersede UberBond modules.

### Task Observer
Approved as a recommendation-first skill-learning observer. It may propose skill diffs but may not silently mutate canon.

### Claude-Mem
Approved as optional subordinate session memory. Repository-native brain/memory and durable evidence always outrank plugin memory.

### Headroom
Approved as bounded context optimization where authoritative originals remain recoverable. Compression is never evidence destruction.

### OmniRoute
Approved for isolated model-routing/fallback evaluation beneath UberBond's own admission/routing policy. It is not a replacement policy brain.

### Strix
Approved only for UberBond-owned or explicitly authorized targets, defaulting to local/test/preview security verification.

### Agent Reach
Approved only for lawful public/authorized research surfaces. UberBond's no-bypass, privacy, source-provenance and platform-policy rules dominate technical reachability.
