## What NULLSTAR is

NULLSTAR is an **internal codename** for the recursive intelligence-acceleration program
inside UberBond. It is not a new North Star and it does not displace anything.

Placement in the existing hierarchy:

- **Sovereign Cognitive Continuum** remains the terminal North Star.
- **Personal Civilization Engine** remains the highest contained life-system organism.
- **NULLSTAR** is an execution-discipline and capability-acceleration directive beneath both.
- The economic company remains a subordinate resource/autonomy organ.

The directive is explicit that it must not be publicly branded as AGI, ASI, singularity,
superintelligence or an intelligence explosion. Internal UB tier labels (UB-100 … UB-X) may
be used **only** when the corresponding sealed evaluation gate is actually passed.
