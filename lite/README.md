# UberBond Cash Engine Lite

A private, minimal operating surface for UberBond's cash-engine path.

This directory is also used as an independent Vercel preview surface. During the September 4, 2026 Avengers closure, its preview build is temporarily exercising the repository-root verification script in `avengers-root-verify.sh` so the root deterministic gates can be independently executed when the primary Vercel project is quota-constrained. This verifier does not widen business, provider, payment, DNS, credential, or customer authority.
