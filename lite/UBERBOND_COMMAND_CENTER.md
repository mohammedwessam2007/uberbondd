# UberBond Wessam Command Center

Status checkpoint: 2026-09-05.

This Lite deployment surface exists so Mohamed can open the UberBond command center directly from an iPad without running the full repository locally.

## Source binding

The cinematic assets under `lite/public/uberbond.*` are copied byte-for-byte from the repository command-center shell. `lite/api/command-center.mjs` exposes a deliberately bounded source snapshot: the canonical 29-organ cognitive topology, public frontier-model candidate catalog summary, the latest recorded GENESIS implementation checkpoint, and exact Vercel deployment identity.

## Truth boundary

The Lite endpoint does not claim that unavailable whole-brain artifacts are live. Missing Feature Genome, Atom Atlas, Synaptic Map, GENESIS runtime, Compute Sovereignty, and Self-Maintainer receipts remain `UNAVAILABLE`. It grants no customer, payment, delivery, spend, provider, repository, deployment, DNS, credential, or production authority.

The current public GitHub repository visibility remains a separate privacy blocker for the long-term Wessam Project and is not concealed by this interface.

## UI evolution law

UberBond may evolve its own command center through bounded candidate changes, visual regression/performance/accessibility/truth tests, reviewable promotion, and rollback receipts. The interface may become more cinematic over time, but visuals never outrank evidence.
