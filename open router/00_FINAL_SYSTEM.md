## Three scarce resources

1. Frontier cognition: scarce and expensive. Spend only on irreducible semantic novelty.
2. Cheap generative breadth: inexpensive but fallible. Use for search, counterexamples, candidate generation, and evidence hunting.
3. Semantic control decisions: extremely cheap when representable as bounded Jev Noul/Choice/Score questions.

## Upgrade: Proof Burn-In vs Certified Compression

### Proof Burn-In

For a new task class or changed Crown:

~~~
direct Crown baseline
+
UberMind candidate pipeline
+
blind paired evaluation
~~~

Burn-in deliberately spends extra money to learn whether compression is safe. It creates paired outcomes, real cost receipts, model-role evidence, Jev shadow observations, applicability boundaries, failure examples, task-archetype labels, and reuse candidates.

### Certified Compression

Only after a bounded architecture earns canonical zero-loss evidence:

~~~
known task archetype
 -> exact/cache/code
 -> certified Jev circuits
 -> minimum adaptive swarm
 -> Crown only for unresolved delta
~~~

The redundant direct-Crown baseline is removed from ordinary production inside that certified region, while shadow Crown audits continue. This is where extreme compression can compound.

## Upgrade: Protected Crown Escrow

Cheap components must never consume the money needed for the real brain.

For a $30 month, maintain a protected primary-Crown reserve. Initial floor: at least $15. Cheap and Jev layers may spend only from non-escrow capacity unless the founder explicitly changes the budget law.

## Upgrade: Cognitive Compute Auction

Each optional compute action bids for budget using:

- expected information gain;
- expected Crown tokens avoided;
- expected quality risk;
- monetary cost;
- latency;
- reuse potential;
- reversibility;
- evidence strength.

A cheap call is not good merely because it is cheap.

## Upgrade: Frontier Thought Bonds

Every expensive Crown call should produce two assets:

1. the answer needed now;
2. a reusable thought bond containing:
   - invariant discovered;
   - decision boundary;
   - applicability domain;
   - invalidators;
   - counterexamples;
   - evidence dependencies;
   - Jev candidate;
   - deterministic-code candidate;
   - tests;
   - drift trigger;
   - estimated future reuse value.

A Crown call that can safely prevent 1,000 future Crown calls is capital expenditure.

## Upgrade: Exact Cognitive Dedup Graph

Content-address tasks, claims, evidence, branches, decisions, artifacts, and Crown deltas.

Before any new inference:
- exact same request + relevant state -> exact reuse;
- evidence already acquired -> multicast it;
- claim already adjudicated in same certified domain -> reuse certified decision;
- duplicate branch -> kill it.

No agent pays to rediscover known information.

## Upgrade: Task-Archetype Compiler

Cluster tasks by decision structure, not surface wording. Crown solves genuinely new archetypes. UberMind tries to compile recurring structures downward to Jev and code.

Semantic similarity alone never grants authority.

## Upgrade: Cognitive CDN

Prefer:
- stable system prefixes;
- content-addressed artifacts;
- exact source slices;
- immutable doctrine references;
- reusable evidence objects;
- tiny fresh deltas.

A cached token is cheaper than a fresh token. A referenced token that does not need to be sent is cheaper than a cached token.

## Upgrade: Evidence Multicast

Acquire evidence once, normalize it once, and let every agent reference the same evidence object. Do not pay three agents to rediscover the same source.

## Upgrade: Second-Crown Insurance

A second frontier model wakes only when:
- first Crown remains materially uncertain;
- disconfirming evidence survives;
- task is critical and hard to verify;
- task-specific Arena identifies a stronger independent specialist;
- a Crown/Jev/certified-circuit disagreement crosses an audit threshold.

## Upgrade: Swarm Stop-Loss

If cumulative cheap-prework spend approaches expected direct-Crown cost and unresolved uncertainty is not shrinking, stop the swarm and buy the Crown directly.

Cheap agents exist to compress frontier cost, not generate token spectacle.

## Final invariant

~~~
QUALITY: fixed to strongest verified frontier
BUDGET: hard
LATENCY / THROUGHPUT: flexible
~~~

Unknown, novel, drifted, or uncertified territory returns upward.
