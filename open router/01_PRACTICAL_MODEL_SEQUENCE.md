# 01 — Practical Real-Life Model Sequence

This file defines roles, not permanent model loyalty.

## Interactive strict sequence

For an important new task:

1. classify task, freshness, and stakes;
2. exact/code/cache/Jev precheck;
3. if task class is novel or uncertified, current Frontier Crown creates an independent baseline;
4. launch two independent cheap model lineages;
5. Jev evaluates disagreement, novelty, and evidence gaps;
6. if needed expand to four;
7. if needed expand to eight or add a task specialist;
8. run Adversarial Synthesis: falsifier, framebreaker, counterfactual, evidence hunter, minority preserver;
9. build exact unresolved-claim dossier;
10. Crown final adjudication;
11. Reality Court;
12. extract Frontier Thought Bond;
13. shadow candidate Jev circuits.

## Certified production sequence

Inside a bounded architecture that already earned zero-loss evidence:

1. exact identity and applicability check;
2. deterministic code if exact;
3. certified Jev circuit if bounded semantic reflex;
4. minimum cheap workers if generative breadth is useful;
5. Jev adaptive-N control;
6. unresolved delta only to Crown;
7. final artifact;
8. sampled Crown shadow audit;
9. drift causes freeze and return to burn-in.

The production sequence is where compression becomes extreme because it does not buy a redundant direct-Crown baseline on every known task.

## Adaptive N

Default:

~~~
N = 2
material disagreement / missing evidence / useful new branch -> 4
still unresolved -> 8
specialized uncertainty -> specialist
irreducible -> Crown
critical Crown conflict -> second Crown
~~~

Expansion considers error-lineage independence, marginal information gain, evidence novelty, contradiction severity, branch survival, expected reduction in Crown tokens, and cost.

## Parallel research, serial truth

Many explorers may run in parallel. Final truth authority is not a popularity contest.

~~~
many explorers
 -> one evidence/claim graph
 -> one adversarial dispute dossier
 -> current Crown or certified equivalent
~~~

## Crown baseline preservation

During burn-in, preserve the Crown's clean first answer separately. The finalizer changes it only where supplied evidence or reasoning independently justifies a change. If the swarm adds no verified improvement, preserve the baseline.

## Model selection law

Do not infer:
- popular = best;
- expensive = best;
- newest = best;
- one benchmark winner = best everywhere;
- cheapest = best value;
- longest context = best reasoning.

The Arena keeps role-specific evidence and refreshes it after material model/provider changes.
