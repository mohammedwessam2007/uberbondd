# 03 — The $30 Economics

## Research target

The goal is to make approximately USD 30 of actual monthly spend produce matched-quality work whose direct strongest-frontier reference cost would be far larger.

Measure:

~~~
Reference Cost Equivalent (RCE)
= cost of strongest verified frontier baseline doing the matched workload directly

Compression Factor
= RCE / actual UberMind all-in spend
~~~

Examples:
- $300 RCE / $30 = 10x
- $750 RCE / $30 = 25x
- $1,500 RCE / $30 = 50x
- $3,000 RCE / $30 = 100x
- $7,500 RCE / $30 = 250x
- $15,000 RCE / $30 = 500x
- $30,000 RCE / $30 = 1000x

Do not count lower-quality work toward RCE.

This is not a permanent split.

## Crown Escrow

At least $15 should initially remain protected for primary frontier cognition.

Cheap/Jev activity spends only if it is necessary, improves evidence, reduces expected Crown cost, or is a controlled experiment likely to improve future compression.

## Counterfactual Spend Estimator

Before an optional swarm:

~~~
A = estimated direct-Crown cost
B = cheap-prework cost + estimated residual Crown cost
~~~

Prefer B only when it is expected to reduce total cost, improve final evidence, or create reusable learning valuable enough to justify the experiment.

The estimator remains advisory until its own predictions are validated.

## Swarm stop-loss

If cheap-prework spend approaches expected direct-Crown cost while unresolved uncertainty is not shrinking:

~~~
STOP SWARM -> BUY CROWN
~~~

Cheap multi-agent systems can become expensive through quantity. The stop-loss prevents that.

## Reuse dividend

Every certified reusable result earns:

~~~
avoided reference frontier cost
- Jev/cache/code maintenance cost
= realized cognitive dividend
~~~

Track this by circuit, task archetype, evidence object, prefix cache, deterministic compiler, and Frontier Thought Bond.

## Budget behavior

Allowed under budget pressure:
- queue;
- defer;
- Batch;
- wait for cheaper identical verified provider route;
- exact cache reuse;
- deterministic execution;
- already-certified Jev reflexes.

Forbidden:
- weaker final model;
- silent reasoning-effort downgrade;
- lossy context deletion;
- skipped required Crown review;
- uncertified cheap substitute.

## How thousands-of-dollars reference equivalent could happen

Extreme compression is multiplicative:

~~~
fewer Crown calls
x less fresh Crown input
x less Crown output
x same-model Batch/deferred savings
x exact reuse
x certified Jev substitution
x deterministic crystallization
x evidence multicast
x branch/task deduplication
x task-archetype reuse
~~~

A 100x result does not require one 100x trick. Several moderate independent savings can multiply.

It must be measured from matched work.
