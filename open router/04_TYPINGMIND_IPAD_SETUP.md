# 04 — TypingMind iPad Setup

## Role

TypingMind is the interactive cockpit, not UberMind's brain.

The intelligence doctrine remains UberMind. OpenRouter is the default model market.

## Minimum founder setup

1. Open TypingMind on iPad.
2. Add one OpenRouter API key.
3. Import the current model roster required for:
   - Jev/System-One;
   - cheap independent worker families;
   - primary Crown;
   - optional second Crown/specialists.
4. Set the OpenRouter account/workspace spend control around the accepted $30 monthly target.
5. Create the UberMind agents/prompts below.
6. Keep model roles replaceable.
7. Never commit API keys or paste them into repo artifacts.

## Core agents

### UBERMIND — Crown
- current strongest verified model for the task;
- independent baseline in burn-in;
- final semantic authority;
- evidence/provenance preserved;
- reusable decision boundaries extracted after solving.

### UBERMIND — Explorer A
- cheap strong model lineage A;
- independent candidate solution;
- assumptions and falsifiable claims;
- evidence discovery.

### UBERMIND — Explorer B
- different cheap strong lineage;
- independent initial reasoning;
- ideally does not see Explorer A before producing its own first pass.

### UBERMIND — Falsifier
- strongest reason leading answer is wrong;
- disconfirming evidence first;
- no consensus reward.

### UBERMIND — Framebreaker
- alternate problem representations;
- hidden assumptions;
- missing objectives;
- category errors.

### UBERMIND — Evidence Hunter
- acquire evidence capable of changing the answer;
- distinguish independent support from repeated sourcing.

### UBERMIND — Minority Preserver
- preserve low-consensus hypotheses with coherent mechanism/evidence;
- state what observation would kill each.

### UBERMIND — Finalizer
- uses current Crown;
- starts from preserved Crown baseline when available;
- treats swarm as evidence/attacks, not votes;
- changes baseline only when independently justified.

## Prompt layout

Put stable content first:
- UberMind laws;
- role definition;
- tool rules;
- quality invariant;
- stable project references.

Put dynamic content last:
- today's task;
- new evidence;
- changed state;
- unresolved claims.

This improves provider prefix/cache reuse where supported.

## Interactive modes

Ordinary:
~~~
you -> Crown or already-certified pipeline -> final
~~~

Important novel:
~~~
Crown baseline
+ Explorer A
+ Explorer B
-> Falsifier/Evidence if needed
-> Crown Finalizer
~~~

Monster:
~~~
Crown baseline
+ adaptive 4-8+ diverse workers
+ tools/research
+ adversarial roles
+ optional second Crown
+ final Crown adjudication
~~~

Do not use monster mode for routine questions.

## When TypingMind is closed

Existing UberBond cloud workers may run already-authorized unattended work:
- queues/events;
- public research/retrieval;
- cheap exploration;
- Jev shadow circuits;
- tests;
- exact deduplication;
- dispute packet preparation;
- same-model Batch/deferred Crown jobs.

No second human-facing UI is required.
