# 10 — Activation Checklist

This is the owner-facing shortest path from canon to reality.

## A. TypingMind

1. Open TypingMind on the iPad.
2. Add the OpenRouter API connection.
3. Import only the current working roster, not hundreds of models into the visible UI.
4. Create these reusable agents:
   - UberMind Crown
   - Explorer A
   - Explorer B
   - Falsifier
   - Framebreaker
   - Evidence Hunter
   - Minority Preserver
   - Crown Finalizer
5. Copy role prompts from 08_PROMPTS.md.
6. Keep stable instructions at the front of prompts.

## B. OpenRouter

1. Create one API key.
2. Store it only in TypingMind / protected UberBond runtime as appropriate.
3. Set the account/workspace spend ceiling near USD 30 for the first month.
4. Do not add extra direct-provider subscriptions until a measured advantage justifies them.
5. Keep provider/model identity visible in receipts.

## C. First roster

Do not hard-code permanent winners.

Start with:
- current Jev/System-One candidate;
- two to four cheap strong model families from different lineages;
- current general Frontier Crown;
- one independent frontier challenger;
- one specialist only when task evidence warrants it.

Refresh exact model IDs and prices at activation time.

## D. First 20 burn-in tasks

Use tasks Mohamed genuinely cares about, not toy benchmark trivia.

For each:
1. run direct Crown baseline;
2. run UberMind pipeline;
3. preserve both outputs;
4. blind/evidence-based compare required dimensions;
5. record token/cost receipts;
6. record whether cheap workers actually changed the Crown result;
7. record Jev/reflex candidates;
8. extract Frontier Thought Bonds.

Do not promote compression based on 20 tasks. This is instrumentation shakeout.

## E. First 100-task evidence block

Stratify by task class:
- research;
- planning;
- coding;
- study/learning;
- document synthesis;
- factual verification;
- creative/strategic work where quality can be meaningfully judged.

Track exact matched performance and costs.

## F. Promotion rule

A bounded compressed architecture enters production only when its canonical evidence gate passes.

Until then it remains shadow or burn-in.

## G. 24/7 activation

Only after interactive receipts are trustworthy:
- enable unattended queue;
- enable read-only/public research preparation;
- enable Jev shadow circuits;
- enable tests/dedup/evidence normalization;
- enable Batch/deferred Crown jobs where model identity/quality is preserved.

Consequential actions remain separately authorized.

## H. Owner action limit

The activation should require essentially:
- OpenRouter key;
- TypingMind connection;
- USD 30 spend ceiling.

Everything else should be prepared by UberBond or automated where safely possible.
