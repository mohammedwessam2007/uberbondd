# 11 — Live Model-Market Refresh

## Why this exists

The system fails its mission if it becomes loyal to the model that happened to be best when this file was written.

The market is continuously changing.

## Daily / event-driven observation

Observe:
- new model releases;
- model revisions;
- context/tool/reasoning capabilities;
- list pricing;
- cache pricing;
- Batch/flex/deferred availability;
- provider availability;
- rate/latency changes;
- known provider incidents.

Catalog presence is discovery evidence, not proof of quality.

## Crown refresh trigger

Trigger a Crown challenge when:
- a major new frontier model appears;
- an incumbent receives a significant revision;
- a specialist materially improves;
- current Crown exhibits repeated task-class failure;
- credible fresh evaluation suggests a challenger may be stronger.

## Cheap-worker refresh trigger

Cheap roles should be more fluid than Crown roles.

A worker can lose its role when another candidate provides better:
- task-class quality;
- independent error diversity;
- evidence utility;
- tool reliability;
- cost;
- latency;
- cache economics.

## Price volatility arbitrage

For the same model/quality contract, route to the cheapest acceptable provider when:
- model identity is preserved;
- required features are supported;
- privacy/data policy is acceptable;
- reliability is sufficient;
- pricing evidence is current.

This is supplier arbitrage, not model downgrade.

## Market snapshot schema

Record:
- observedAt;
- model ID;
- provider;
- model revision if observable;
- task-class evidence;
- input/output/cache prices;
- context;
- reasoning settings;
- tool support;
- structured-output support;
- availability;
- privacy/data handling;
- benchmark/real-use evidence pointers;
- Crown/challenger/worker role state.

## Automatic succession principle

Frontier progress is donated intelligence.

A stronger new model is not a threat to UberMind. After proof, it raises the Crown and therefore raises every future compressed architecture's quality target.

The organism should continuously ratchet upward with the market.
