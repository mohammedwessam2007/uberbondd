## What is theorem-like

If all of these are true:

1. the execution is E0, E1, E2, E3, or E4;
2. the semantic proof is independently verified;
3. the matched obligation and quality contract are content-addressed;
4. the dependencies and Crown revision remain valid;
5. the direct-frontier counterfactual uses the cheapest legitimate route capable of doing the same matched work;
6. all direct optimizations that could reduce that counterfactual have been credited;
7. execution counts are observed rather than invented;
8. actual UberMind cost is observed and includes all cash-metered cognition;

then the avoided direct-frontier reference cost is an arithmetic consequence of the inputs.

No ceremonial LLM judge is required to ask whether byte-identical replay is "as good", whether deterministic arithmetic "looks equal", or whether a fully covered Crown-authored finite policy is "roughly similar".

## What is not theorem-like

This does not prove:

- arbitrary natural-language interpretation;
- E5 empirical equivalence;
- E6 fresh novelty quality;
- economic market value of output;
- raw GPU FLOPs consumed;
- customer willingness to pay;
- literally infinite cognition.

Those require their own evidence.

## Conservative counterfactual law

Never use naive:

```
N executions × full fresh Crown API call
```

when the direct frontier route could legitimately use a cheaper mechanism.

For repeated identical requests, direct response caching must be credited.

For repeated stable prefixes, prompt-cache read pricing must be credited.

For delay-tolerant work, Batch/Flex must be considered.

For cheaper same-quality provider routes, the cheaper legitimate route must be considered.

Only the remaining conservative direct cost enters the ledger.
