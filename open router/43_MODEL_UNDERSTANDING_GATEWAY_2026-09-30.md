## Core correction

Model understanding can eliminate **unnecessary testing**, but not all testing.

Three evidence classes must stay separate:

1. **Mechanistic / contractual facts** — architecture disclosures, context limits, reasoning modes, tool support, cache semantics, provider tariffs.
2. **By-construction equivalence** — E0-E4 paths whose quality is already established by exact identity, deterministic derivation, verified transformation, exhaustive policy, or a proof-carrying bounded circuit.
3. **Open-ended capability** — E5/E6 behavior such as novel strategy, ambiguous research judgment, or a new task-class Crown.

Classes 1 and 2 can remove large amounts of repeated model-vs-model testing.
Class 3 cannot be made certain merely from model architecture.
