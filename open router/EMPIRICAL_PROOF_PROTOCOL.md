# Empirical Proof Protocol

Status: required before claiming $30 frontier-equivalent compression.

## Why this exists

The architecture can be excellent while the economics fail.

The only acceptable proof is paired work on fresh tasks with real cost receipts and current frontier baselines.

## Core comparison

For each task class:

```
A = strongest verified market Crown solving directly
B = UberMind using any lawful combination of:
    code
    retrieval
    caches
    Jev
    cheap heterogeneous workers
    tools
    adversarial synthesis
    sparse Crown adjudication
```

Quality condition:

```
Quality(B) >= Quality(A)
```

Economic condition:

```
Cost(B) < Cost(A)
```

## Fresh-task design

Use tasks that are:

- not previously optimized against;
- representative of real UberBond work;
- difficult enough to discriminate;
- independently scored when possible;
- sealed before architecture tuning;
- diverse across task classes.

Avoid benchmark leakage.

## Paired task-level outcome

Each task should record:

```
BASELINE_CORRECT
BASELINE_INCORRECT
BASELINE_ABSTAINED

UBERMIND_CORRECT
UBERMIND_INCORRECT
UBERMIND_ABSTAINED
```

A paired regression occurs when the baseline succeeds on a required dimension and UberMind fails.

Aggregate score alone is insufficient.

## Blind evaluation

Where practical:

- strip model names;
- randomize answer order;
- use task-specific criteria;
- use independent evaluator/custodian;
- separate selector from synthesizer.

## Quality dimensions

Select only those relevant to the task, but preserve at least:

- correctness;
- factual grounding;
- reasoning completeness;
- instruction following;
- uncertainty discipline;
- safety/authority compliance;
- artifact quality;
- test success for code;
- evidence quality for research.

## Cost receipt

Record:

```
provider
model
revision if observable
reasoning setting
service tier
fresh input tokens
cached input tokens
output tokens
reasoning tokens if exposed
provider fee
tool/search charges
all-in cost
latency
```

Do not infer exact spend from list pricing when authoritative billing is available.

## Reference cost equivalent

Prefer observed direct baseline cost.

If direct observation is not available, label any reconstruction as estimated.

Never use a hypothetical expensive baseline to inflate the compression factor.

## Jev proof

For each candidate circuit:

```
same fresh state
 -> Crown/current mechanism decision
 -> Jev shadow decision
 -> observed reality outcome where applicable
```

Promotion requires current canonical zero-loss law.

## Multicast proof

For each shared Crown decision:

Record:

- number of consumers;
- whether each consumer truly depended on the same proposition;
- whether one call replaced multiple otherwise-required frontier calls;
- whether any consumer required context that was lost during coalescing.

## Decision-DAG proof

Track:

- semantic nodes in artifact;
- nodes reused exactly;
- nodes invalidated;
- nodes recomputed;
- quality outcome after incremental recomputation.

## Crown Thought Capital proof

For each Crown call, track later realized reuse.

Do not count a proposed Jev circuit or code candidate as realized savings.

Count only:

- actual future frontier calls avoided;
- actual tasks served;
- actual reference cost avoided.

## Negative knowledge proof

Count only repeated work genuinely prevented by a valid still-current failure record.

## Crown succession proof

When a new model becomes a Crown candidate:

- freeze old comparison set;
- add fresh hidden tasks;
- compare current Crown vs candidate;
- avoid cost-based promotion;
- promote by quality first;
- then re-run compression architecture against the stronger baseline.

## Monthly report

At the end of each month publish an internal receipt:

```
Crown calls avoided

```

## Claim language

Allowed after evidence:

```
On task class X over N fresh paired tasks, UberMind had zero observed paired regressions and cost Y% less than baseline Z.
```

Not allowed without much broader evidence:

```
UberMind is globally the best AI system.
UberMind always equals the strongest model.
$30 is equivalent to $10,000 every month.
```

## First proof milestone

A credible first milestone is:

- at least one current Crown identified;
- 40+ fresh paired tasks in one meaningful class;
- real all-in cost receipts;
- zero observed paired regressions under the canonical gate;
- at least one Jev circuit in shadow;
- at least one realized cache/multicast/reuse saving;
- no hidden downgrade.

This still does not prove universal equivalence.

## Ultimate success criterion

The research program is succeeding if, as frontier models improve:

- UberMind's final quality floor rises with them;
- actual spend grows much slower than direct frontier reference cost;
- repeated cognition migrates to certified Jev/code;
- the measured compression factor increases;
- no intentional quality downgrade is needed.
