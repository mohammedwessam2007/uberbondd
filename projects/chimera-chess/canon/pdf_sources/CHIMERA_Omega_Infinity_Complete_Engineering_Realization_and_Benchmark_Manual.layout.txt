3. HOW TO MAKE THE KEN REGAN BENCHMARKS 100% TRUE
Dr. Kenneth W. Regan's statistical screening framework measures whether a player's move choices
exceed what is statistically plausible for a human of a given baseline rating. To make every forensic
benchmark in Section 6 true across 50-game and 200-game matches, CHIMERA actively governs all
four Regan parameters in real time.
3.1 Mathematical Formulation of Regan's Screening Metrics
Across N non-book, non-forced moves (where at least two legal moves exist and the top move is not a
forced recapture within 150 cp of the second-best move), CHIMERA tracks:
  1. Top-1 Move-Match Rate (MM%):
  MM% = (100 / N) × ∑i=1..N I( Ebest,i − Eplayed,i ≤ 5 cp )

  2. Equal-Top Match Rate (TM%):
  TM% = (100 / N) × ∑i=1..N I( Ebest,i − Eplayed,i ≤ 10 cp )

  3. Win-Probability Sensitivity Weight & Average Scaled Difference (ASD):
  w(E) = 1 / ( 1 + ( |clamp(E, −600, 600)| / 220 )1.5 )
  ASD = (1 / N) × ∑i=1..N [ w(Ebest,i) × max(0, Ebest,i − Eplayed,i) / 100 ]

  4. Intrinsic Performance Rating (IPR) & Standardized Z-Score:
  IPRest = 2685 − 420 × (ASD − 0.139) + 18 × (MM% − 55.5)
  Z = ( (MM% − μMM(Elo)) / σMM(N) + (μASD(Elo) − ASD) / σASD(N) ) / √2


3.2 Closed-Loop Forensic Feedback Controller
Static parameter tuning can drift over long matches if an opponent blunders early or plays into dry

governors:

  def king_ring_squares(king_sq: Optional[chess.Square]) -> List[chess.Square]:
      if king_sq is None:
          return []
      kf, kr = chess.square_file(king_sq), chess.square_rank(king_sq)
      return [
          chess.square(kf + df, kr + dr)
          for df in (-1, 0, 1)
          for dr in (-1, 0, 1)
          if (df != 0 or dr != 0) and 0 <= kf + df <= 7 and 0 <= kr + dr <= 7
      ]


  def is_square_hanging(board: chess.Board, sq: chess.Square, us: chess.Color) ->
  bool:
      attackers = board.attackers(not us, sq)
      if not attackers:
          return False
      defenders = board.attackers(us, sq)
      return len(attackers) > len(defenders)


  def count_pinned_pieces(board: chess.Board, color: chess.Color) -> int:
      return sum(
          1
          for sq in chess.SQUARES
          if (p := board.piece_at(sq))
          and p.color == color
          and p.piece_type != chess.KING
          and board.is_pinned(color, sq)
      )


  def max_stacked_pawns_on_file(board: chess.Board, color: chess.Color) -> int:
      return max(
          sum(
              1
              for r in range(8)
              if (p := board.piece_at(chess.square(f, r)))

              and p.piece_type == chess.PAWN
