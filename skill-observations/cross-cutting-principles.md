# UberBond Skill Cross-Cutting Principles

1. Current repository/executable truth and durable external evidence outrank skill/plugin memory and model prose.
2. Capability never creates authority.
3. Prefer structural enforcement, tests and fail-closed contracts over merely repeating important prose.
4. Dedupe before adding a new skill, agent, runtime, ledger, scheduler or truth system.
5. Preserve authoritative originals when using compression or secondary memory.
6. Record exact provider/model/source identity whenever routing or fallback can change who performed work.
7. Observe and propose improvements from real friction, then review/test/merge them rather than silently self-mutating.
