# Quickstart

## Validate

```bash
python scripts/validate_package.py
```

## Install user-level intelligence

```bash
bash installation/install_user.sh
```

## Preview project changes

```bash
python installation/install_project.py --project /path/to/repo
```

## Apply project integration

```bash
python installation/install_project.py --project /path/to/repo --apply
```

## Start

```bash
elite-apex
```

## Maximum one-shot mission

```bash
elite-apex-max
```

## Architecture-only

```bash
elite-apex-plan
```

## Independent review

```bash
elite-apex-review
```

## Opt-in agent team

```bash
elite-apex-team
```

Agent-team mode is experimental and should be used only for non-overlapping workstreams.
