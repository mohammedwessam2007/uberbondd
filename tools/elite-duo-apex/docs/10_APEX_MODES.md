# Apex modes

## `elite-apex`

- Sonnet 5 xhigh main session
- best default for serious implementation
- architecture and review agents still override to max

## `elite-apex-max`

- Sonnet 5 max main session
- use for one exceptionally difficult finite mission
- highest Sonnet token consumption
- no other model

## `elite-apex-plan`

- Sonnet 5 max
- plan permission mode
- architecture, adjudication, threat models, migration review
- no application edits

## `elite-apex-review`

- Sonnet 5 max
- apex-orchestrator role
- fresh-context evidence review and verdict

## `elite-apex-team`

- Sonnet 5 max
- enables experimental Claude Code agent teams
- requires explicit user request and exclusive file ownership
- never the default
