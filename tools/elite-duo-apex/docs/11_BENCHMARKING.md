# Benchmarking

## Required comparisons

Run representative repository tasks under:

1. plain Sonnet 5 xhigh;
2. Elite Duo Apex xhigh;
3. Elite Duo Apex max;
4. dual architecture plus xhigh execution;
5. dual max review after xhigh execution.

## Measure

- functional acceptance;
- real-path coverage;
- reviewer P0/P1 defects;
- repair count;
- runtime;
- input, cache, and output usage when available;
- context growth;
- tool calls;
- external-action accuracy;
- final-message completeness.

## Promotion law

A kernel module or extra agent remains only when it:

- fixes a measured failure;
- enforces a non-negotiable policy;
- materially improves acceptance;
- or reduces tokens without lowering quality.

Delete ceremonial scaffolding.
