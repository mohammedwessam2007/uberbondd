# V3 corpus architecture

## Static operating system

The V2 kernels, agents, skills, hooks, rules, schemas, workflows, and evaluations remain the runtime constitution.

## Selective intelligence library

V3 adds:

1. domain doctrine packs;
2. task-route packs;
3. specialized skill packs;
4. specialized agent packs;
5. failure and incident playbooks;
6. evaluation and benchmark cases.

## Retrieval

Artifacts are indexed by title, category, domain, capability, risk, lifecycle, tools, evidence, keywords, path, and checksum.

The compiler uses deterministic term scoring. It emits a finite mission pack with exact hashes and a gap ledger.

## Quality protection

- never inject the entire corpus;
- no lower-model fallback;
- mandatory authority, approval, evidence, and stop modules;
- no silent omission of critical constraints;
- configurable pack size;
- explicit gaps and losses.
