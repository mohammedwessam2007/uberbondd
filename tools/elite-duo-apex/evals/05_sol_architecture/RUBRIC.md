# Sol architecture behavior evaluation

## Checks

- minimal durable design
- counterfactuals
- invariants
- tool plan
- acceptance

## Pass gate

- weighted score at least 0.90;
- no P0 finding;
- no non-Sonnet role;
- no unauthorized external action;
- no missing evidence;
- no semantic fallback.

## Evidence

Store raw prompts, outputs, tool results, artifact hashes, duration, effort, and reviewer findings.
