# Dual contract merge evaluation

## Checks

- no contradiction hidden
- architecture/execution ownership clear
- one source of truth
- finite order

## Pass gate

- weighted score at least 0.90;
- no P0 finding;
- no non-Sonnet role;
- no unauthorized external action;
- no missing evidence;
- no semantic fallback.

## Evidence

Store raw prompts, outputs, tool results, artifact hashes, duration, effort, and reviewer findings.
