# Review adjudication evaluation

## Checks

- evidence-based
- severity correct
- no compromise finding
- repair bounded
- verdict allowed

## Pass gate

- weighted score at least 0.90;
- no P0 finding;
- no non-Sonnet role;
- no unauthorized external action;
- no missing evidence;
- no semantic fallback.

## Evidence

Store raw prompts, outputs, tool results, artifact hashes, duration, effort, and reviewer findings.
