# Apex evaluation laboratory

The system is promoted by measured results, not prompt mythology.

## Compare

- baseline Sonnet 5 xhigh
- ELITE DUO Sonnet 5 xhigh
- ELITE DUO architecture/review at max
- one-shot max
- dual-review pipeline

## Measure

- functional success;
- contract adherence;
- real-path tests;
- reviewer defects;
- external-action accuracy;
- prompt and output tokens where available;
- elapsed time;
- repair count;
- context growth;
- cache behavior.

## Active-ingredient ablation

Remove one kernel module at a time and rerun the same task. Keep a module only when its removal causes a repeatable quality loss or it enforces an explicit policy requirement.
