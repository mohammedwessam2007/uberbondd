# ELITE DUO APEX ULTRA CORPUS V3

V3 retains the complete V2 operating system and adds a large selective intelligence library.

The corpus is intentionally large on disk and intentionally small in each live context.

## Core law

> Search widely, load narrowly, reason deeply.

Claude should not read thousands of modules at startup. The corpus compiler selects a mission pack containing only the most relevant domain doctrine, invariants, failure modes, skills, agents, workflows, tests, review rubrics, controls, and benchmark cases.

## Model law

Every AI role remains Claude Sonnet 5 at high, xhigh, or max effort. The corpus introduces no cheaper-model route and no hidden external model call.

## Fast use

```bash
python library/apex_library.py stats
python library/apex_library.py search "durable payment reconciliation concurrency"
python library/apex_library.py materialize   --query "durable staged acquisition worker with crash recovery"   --output MISSION_INTELLIGENCE_PACK
```

Then launch `elite-apex` and provide the mission plus the generated pack.
