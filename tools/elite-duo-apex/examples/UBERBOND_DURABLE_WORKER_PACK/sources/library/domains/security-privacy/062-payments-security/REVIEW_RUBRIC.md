# Payments Security review rubric

Score 0 to 4 for:

- mission fidelity;
- authority and evidence;
- architecture completeness;
- operational reachability;
- failure-path coverage;
- sequencing and concurrency safety;
- security and privacy;
- rollback and observability;
- external-action accuracy;
- final deliverable completeness.

Pass requires 36/40, no zero, no unresolved critical finding, fresh-context review, and an allowed verdict.
