# Selective intelligence library

## Search

```bash
python library/apex_library.py search "payment worker idempotency stale provider response"
```

## Filter a category

```bash
python library/apex_library.py search "prompt injection authority" --category controls
```

## Materialize a finite mission pack

```bash
python library/apex_library.py materialize   --query "international payment reconciliation for an Egyptian founder"   --output MISSION_INTELLIGENCE_PACK   --limit 56   --max-bytes 1500000
```

The compiler always includes the apex constitution and then selects balanced results across categories.

## Why deterministic retrieval

The corpus is too large to place in one context. Deterministic retrieval is reproducible, cheap, hashable, and cannot quietly call another model.

The Sonnet 5 mission compiler may remove irrelevant selected modules or report missing knowledge, but it must preserve mandatory authority, security, evidence, and stop modules.
