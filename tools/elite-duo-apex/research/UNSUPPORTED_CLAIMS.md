# Unsupported claims rejected by V2

- “This reproduces Fable 5’s actual intelligence.”
- “This reproduces GPT-5.6 Sol Max’s actual intelligence.”
- “A hidden billing trick makes premium models count as Sonnet.”
- “More prompt text equals more intelligence.”
- “A multi-agent team always beats a single agent.”
- “Reviewer agreement proves correctness.”
- “Passing tests proves production readiness.”
- “Prompt caching transfers across models.”
- “Model switching preserves hidden reasoning.”
- “A skill or agent file is enforcement.”

V2 distinguishes behavioral guidance, client enforcement, deterministic evidence, and actual model capability.
