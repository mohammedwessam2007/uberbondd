# Fable capability map

**Source basis:** `ANT-FABLE-PROMPT`  
**Status:** source-derived public guidance, verified 2026-08-01

## Findings

- Long-horizon autonomy over extended goal-directed runs.
- First-shot correctness on complex well-specified work.
- Stronger code review and repository-history debugging.
- Ambiguity navigation across multithreaded requests.
- More dependable delegation to parallel or long-lived subagents.
- Professional enterprise artifact production and vision handling.
