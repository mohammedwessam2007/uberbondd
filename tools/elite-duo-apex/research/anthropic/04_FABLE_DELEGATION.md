# Fable delegation

**Source basis:** `ANT-FABLE-PROMPT`  
**Status:** source-derived public guidance, verified 2026-08-01

## Findings

- Independent subtasks can be delegated in parallel.
- Long-lived agents can preserve context and cache value.
- The orchestrator should continue useful work while independent agents run.
- Intervention is appropriate when an agent goes off track or lacks context.
