# Fable autonomy boundaries

**Source basis:** `ANT-FABLE-PROMPT`  
**Status:** source-derived public guidance, verified 2026-08-01

## Findings

- Assessment requests should not silently become implementation.
- State-changing commands require evidence supporting that action.
- Reversible actions following from an authorized build request may proceed.
- Destructive, irreversible, scope-changing, or user-only decisions require a pause.
