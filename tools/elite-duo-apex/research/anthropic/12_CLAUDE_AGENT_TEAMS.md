# Claude Code agent teams

**Source basis:** `ANT-TEAMS`  
**Status:** source-derived public guidance, verified 2026-08-01

## Findings

- Teams provide separate Claude instances with shared tasks and direct messaging.
- Teams add substantial token and coordination overhead.
- They fit independent research, competing hypotheses, and cross-layer ownership.
- They are a poor fit for sequential tasks or same-file editing.

## ELITE DUO implementation

Apex team mode is opt-in and requires non-overlapping ownership.
