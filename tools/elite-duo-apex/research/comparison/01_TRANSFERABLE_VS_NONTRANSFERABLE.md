# Transferable versus non-transferable

**Source basis:** `ANT-FABLE-PROMPT`  
**Status:** source-derived public guidance, verified 2026-08-01

## Findings

- Transferable: procedures, role design, tool policies, memory formats, verification, and output contracts.
- Non-transferable: model weights, latent capability, private reasoning, provider safeguards, and model-native tools.

## ELITE DUO implementation

The package labels itself a Sonnet-only approximation and never impersonates the source models.

## Evidence rule

This module transfers operating principles only. It does not claim to reproduce the source model's weights or hidden reasoning.
