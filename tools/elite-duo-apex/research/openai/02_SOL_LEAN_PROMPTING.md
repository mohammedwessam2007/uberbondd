# Lean prompting

**Source basis:** `OAI-56-GUIDE`  
**Status:** source-derived public guidance, verified 2026-08-01

## Findings

- Repeated instructions and excessive examples can reduce performance.
- Expose only relevant tools.
- State autonomy rules once.
- Keep examples only when they encode a measured requirement.
- Track growing session context.

## ELITE DUO implementation

Apex kernels are modular and role contexts load only the needed modules.
