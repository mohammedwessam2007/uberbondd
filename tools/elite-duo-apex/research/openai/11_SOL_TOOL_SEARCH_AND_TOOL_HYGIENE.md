# Tool hygiene

**Source basis:** `OAI-56-SOL`  
**Status:** source-derived public guidance, verified 2026-08-01

## Findings

- GPT-5.6 Sol supports many tools, including web, files, shell, patching, skills, computer, and MCP.
- More tools are not always better.
- Relevant-tool exposure reduces confusion and token overhead.
